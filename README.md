# Ispar client releases

Releases of the Ispar client for Asheron's Call. This repo holds only the releases and their terms; the client's code is not public.

To install, download `Ispar-client-vX.Y.Z-setup.exe` from the [latest release](https://github.com/ispar-ac/releases/releases/latest) and run it. An installed client checks here for updates itself.

Each release also carries `SHA256SUMS.txt`, to check your download.

The client is free to use for playing on Ispar under [TERMS.txt](TERMS.txt). The open parts it ships keep their own licences, listed in [THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt).
